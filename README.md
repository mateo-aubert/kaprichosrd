# Kaprichos RD

Este repositorio documenta mi participación en el desarrollo de la web y del panel de administración de Kaprichos RD, empresa dedicada a la instalación, reposición y mantenimiento de máquinas expendedoras.

## Mi contribución

- Desarrollé funcionalidades de la aplicación web y adapté la interfaz para móviles.
- Ajusté el bloque principal de la página de inicio para que las imágenes grandes cupieran en pantalla en escritorio y las pequeñas se mostraran sin dejar huecos.
- Corregí el guardado de bloques con vídeo en el editor y simplifiqué el formulario al eliminar el campo de imagen de portada.
- Colaboré en el desarrollo de la API y en la gestión de la base de datos.

## Tecnologías

React · Tailwind CSS · Node.js · PostgreSQL
