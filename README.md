## Proyectos

### Kaprichos RD · Plataforma web de vending

Colaboré en el desarrollo full stack de la web corporativa y del panel de administración de Kaprichos, una empresa que instala, repone y mantiene máquinas expendedoras.

- Desarrollé funcionalidades de la aplicación web y adapté la interfaz para móviles.
- Ajusté el bloque principal de la página de inicio para que las imágenes grandes cupieran en pantalla en escritorio y las pequeñas conservaran su tamaño sin dejar huecos.
- Trabajé en la API y la base de datos. Corregí el guardado de bloques con vídeo y simplifiqué su edición al eliminar el campo de imagen de portada.

**Tecnologías** · React, Tailwind CSS, Node.js y PostgreSQL.

[Ver la web](https://kaprichosrd.com/) · [Panel de administración](https://kaprichosrd.com/admin)
